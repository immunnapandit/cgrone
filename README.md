# CGR ONE — Visa & Immigration Consultancy (React)

A pixel-inspired React recreation of the CGR ONE visa/immigration consultancy landing page, built with:

- **React 18 + Vite**
- **Tailwind CSS** (custom red/black/offwhite palette matching the original)
- **Framer Motion** for scroll reveals, hover micro-interactions, an animated marquee strip, a flying-plane hero animation, and animated stat counters / progress bars
- **React Icons** for all iconography

## Fonts
- Headings: **Poppins** (600–800 weight)
- Body: **Jost** (300–500 weight)
Both loaded via Google Fonts in `src/index.css`, matching the bold-heading / light-body typography of the original design.

## Sections included
1. Sticky Navbar with mobile menu
2. Hero with animated flight path + 3 overlapping feature cards
3. Who We Are (About)
4. Red animated marquee strip
5. Outstanding Immigration Visa Services (4 service cards)
6. Why Choose Us (split red/white with animated progress bars)
7. Countries We Support (6 country cards)
8. 3-step Working Process
9. Stats / "Ready to fly" CTA with animated counters
10. Latest News / Blog
11. Contact form
12. Footer with newsletter + social links
13. Scroll-to-top button

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

Images are pulled from Unsplash placeholder URLs — swap `src/components/*.jsx` image URLs with your own licensed photography before going live.
